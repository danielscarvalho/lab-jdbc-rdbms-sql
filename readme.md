### LAB

1. Obtero string de conecxão do seu BD PostgreSQL no Neon
2. Ajustar o código para acessar sua base de dados
3. Ajustar .run para .bat se for trabalhar em Windows (Linux recomendado)
4. Criar e experimentar CRUD completo: Java + JDBC + SQL
   - Create ➽ INSERT (POST)
   - Read   ➽ SELECT (GET)
   - Update ➽ UPDATE (PUT)
   - Delete ➽ DELETE (DELETE)
